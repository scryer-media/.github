# Scryer Media

Modern tools for media management.

This workspace is split across a few focused repositories. For product details, screenshots, installation guides, and end-user documentation, start at [www.scryer.media](https://www.scryer.media/).

## Repositories

- [scryer](https://github.com/scryer-media/scryer) - the main app for movies, TV series, and anime
- [weaver](https://github.com/scryer-media/weaver) - the all-in-one Usenet downloader
- [scryer-plugins](https://github.com/scryer-media/scryer-plugins) - plugin packages and registry metadata for Scryer
